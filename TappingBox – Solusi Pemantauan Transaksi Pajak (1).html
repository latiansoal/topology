TappingBox

Perangkat dan aplikasi yang menangkap data transaksi usaha secara otomatis dan mengirimkannya ke dashboard pendapatan daerah.

Sekilas TappingBox

  • Sistem pemantauan transaksi penjualan yang dipasang di lokasi Wajib Pajak.
  • Mengirim data transaksi penjualan (dan pajaknya) ke server Badan Pendapatan, sebagai data pembanding laporan SPTPD bulanan.
  • Tidak mengganggu transaksi di Wajib Pajak, dan memudahkan Dinas Pendapatan mengukur potensi pajak Hotel, Restoran, Parkir, dan Hiburan.

Satu dashboard, dua jalur data

Transaksi bisa diambil dari sistem kasir yang sudah ada, atau dari perangkat Subaga bagi usaha yang masih manual.

TappingBox: pilih sesuai cara usaha mencetak struk

Tapping Printer

Untuk usaha yang pasti atau sering mencetak struk, misalnya restoran cepat saji.

  • Dipasang di antara mesin kasir dan printer
  • Menangkap data transaksi lalu mengirimkannya ke Dinas Pendapatan

Tapping Server

Untuk usaha yang tidak selalu atau jarang mencetak struk, misalnya hotel dan resort.

  • Dipasang di jaringan LAN internal hotel atau resort
  • Hotel menyediakan akses read-only ke database transaksi (production atau staging)
  • Data yang disiapkan: jenis database, nama database, port, nama tabel, username, password

Data yang dikirim: Device ID, No WP & struk, waktu, dan nilai transaksi.

Tapping Agent

Aplikasi di sisi Wajib Pajak

Dipasang di komputer kasir atau server Wajib Pajak. Mengambil data dan mengirimkannya ke server Bapenda.

  • Kredensial DBMS
  • Akses internet
  • Penyimpanan cukup
MySQLOracleSQL ServerSQLitePostgreSQLFirebaseTXT

Layanan online di sisi Bapenda

Dipasang di server Bapenda. Mengambil data dari server, cloud, atau dashboard Wajib Pajak.

  • Dokumen API
  • Login credential untuk dashboard atau API

Tapping Bluetooth

Modul Bluetooth ditambahkan pada perangkat TappingBox. Dengan metode Printer Tapping, data transaksi yang dikirim ke printer Bluetooth ikut diambil.

Sudah diuji di berbagai merek POS berbasis cloud yang mencetak bukti transaksi lewat printer Bluetooth.

Sumber data lokal maupun cloud dikirim lewat Tapping Agent ke Server Dashboard PHR Online.
